# AI Money Hunters — минимальная рабочая версия (v0.1)

## Запуск с iPhone, без вашего Mac/ПК, $0
1. **Telegram**: напишите @BotFather → `/newbot` → сохраните токен.
2. **GitHub** (приложение или github.com в Safari): создайте **приватный** репозиторий, загрузите содержимое этой папки
   (на iPhone удобнее: загрузите ZIP на github.com → "Add file → Upload files" после распаковки в «Файлах»).
3. Repo → Settings → Secrets and variables → Actions → добавьте секрет `TELEGRAM_BOT_TOKEN`.
4. Actions → "money-hunters" → Run workflow. Напишите боту `/start` — он ответит вашим chat id.
5. Добавьте секрет `TELEGRAM_OWNER_ID` с этим числом, снова Run workflow, снова `/start`. Бот отвечает только вам.
6. Дальше цикл идёт по расписанию (каждые ~15 мин, GitHub может задерживать) и без вашего телефона. Команды обрабатываются при следующем запуске, а не мгновенно.

Источники: GitHub-баунти включены; свои RSS добавляйте в `sources.json`:
`{"rss":[{"name":"имя","url":"https://...","division":"B"}]}`

## Что реально работает
Реестр 108 агентов, SQLite, цикл CEO (поиск → антискам → оценка чистой выгоды → задача), финучёт с 6 категориями и защитой от дублей,
одобрение выплат, версии стратегий, 20 команд Telegram, тесты.

## Чего НЕТ (честно)
- Система сама **не выполняет** работу на платформах (регистрации, отправка результатов, вывод денег): задачи уходят вам в /tasks.
- Автоотправка средств не реализована намеренно. Выплаты — только запись и /approve.
- Контент-фабрика, фриланс-исполнители и партнёрки пока «логические агенты» без исполнителей.
- Поступления попадают в учёт только вручную: `/log_received источник сумма tx_или_ссылка`.
